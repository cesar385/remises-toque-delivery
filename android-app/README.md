# App Android del conductor (TOQUE! Conductor)

La app se arma y se compila sola en GitHub con el archivo `.github/workflows/app-android.yml`
(pestaña **Actions → App Android → Run workflow**). No hace falta subir nada más a esta carpeta.

Descarga del APK: https://github.com/cesar385/remises-toque/releases/latest/download/toque-conductor.apk

La firma se guarda como secreto de GitHub `KEYSTORE_B64` (Settings → Secrets and variables → Actions). Nunca subas la clave al repositorio.
